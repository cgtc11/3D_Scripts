SpringMax 018 操作マニュアル

3ds Maxの親子ボーンへ、スプリング・風・重力・当たり判定をベイクする補助ツールです。

対象: 3ds Max 2025以降PySide6単一PYファイル
目次 1. 概要 2. 起動方法 3. 基本的な使い方 4. 骨の選択ルール 5. スプリング設定 6. キー設定 7. 当たり判定 8. 風 9. 重力 10. 基準角度 11. 骨ポーズ 12. 設定例 13. トラブル対処 14. 注意事項

1. 概要

SpringMaxは、選択した親子階層をフレームごとに計算し、揺れや外力を3ds Maxの回転キーとして生成するツールです。髪、紐、尻尾、アクセサリー、ケーブルなどの二次動作を想定しています。

できること

  • スプリングによる遅れ・揺れ
  • 球 / ボックスとの衝突
  • 風による先端側のなびき
  • 方向指定できる重力
  • 保存した基準角度への復帰
  • 分岐した選択階層の一括計算

基本思想

物理シミュレーターではなく、元の姿勢へ戻ろうとする骨チェーンに、慣性・風・重力・衝突補正を加える方式です。計算結果はキーへベイクされます。

Undo: 「適用」1回分は1つのUndoとして処理されます。結果がおかしい場合は Ctrl + Z 1回で計算前へ戻せます。

2. 起動方法

SpringMax_018.py を任意の場所へ保存します。
3ds Max 2025以降を起動します。
メニューの「スクリプト」→「スクリプトを実行」から SpringMax_018.py を選択します。
「SpringMax 018」ウィンドウが表示されれば起動完了です。
追加のpipライブラリは不要です。3ds Max付属のPython / PySide6 / pymxsを使用します。

3. 基本的な使い方

揺らしたい親子の骨を、親から子まで連続した状態で選択します。
「スプリング」「ねじれ」「張力」などを調整します。最初はデフォルト値で構いません。
必要なら「当たり判定」「風」「重力」を設定します。
計算したいアニメーション範囲を確認します。
「適用」を押します。
タイムラインを再生して確認し、必要ならUndoして値を調整して再計算します。
重要: 最後の選択ノードは、その1つ上の骨が向くための「終端参照」として使われます。末端まで動かしたい場合は、最後に動かしたい骨の子 / End Bone / Pointなどまで選択しておくと確実です。

4. 骨の選択ルール

基本は「親 → 子」がつながった選択です。ローカルX軸が子方向を向くリグを想定しています。

直列チェーン

Bone001 → Bone002 → Bone003 → Bone004 → End

このように選択すると、親側から順番に計算します。

分岐チェーン

Bone001
├─ Bone002 → Bone003 → Bone004
└─ Bone007 → Bone008 → Bone009

複数の枝を同時選択できます。「分岐骨も計算」がONなら、分岐点自身も1回だけ計算し、その下の各枝を別チェーンとして処理します。

設定初期値動作
ルート骨も計算OFFOFFでは選択群の一番上を固定ドライバとして扱います。ONなら一番上の骨も揺れ・風・衝突の対象です。
分岐骨も計算ONONでは分岐点の骨も計算します。OFFでは分岐点を固定し、その下の枝だけを計算します。

5. スプリング設定

項目初期値説明調整の目安
スプリング0.700元の基準姿勢へ戻ろうとする動きと、前フレームからの遅れ方の中心となる値です。まず0.7。柔らかい二次動作は0.6～0.8付近から調整。
ねじれ0.700骨のUp方向 / ロール方向の追従を調整します。保存角度または計算開始角度へ戻る安定化も入っています。ロールが不安定なら高め側から確認。
張力0.500子・孫側とのつながりを意識して、関節の曲がりを馴染ませます。関節がバラバラに見える場合に調整。
しなり0.000骨長方向の伸縮追従を許可します。0なら基本的に骨長を維持します。通常のBoneは0推奨。伸縮を意図するときだけ使用。
慣性0.000前フレームまでの移動傾向をどの程度引きずるかを調整します。揺れを残したい場合に少しずつ上げます。
サブフレーム11フレーム内の計算回数。値を増やすほど細かく計算します。高速動作や衝突で不安定な場合は2～4を試します。
サブフレームを増やすと計算時間とキー数が増えます。「サブフレームキーを削除」がONなら、計算後に整数フレーム以外のキーを削除します。

6. キー設定

項目説明
アニメーション範囲を使用3ds Maxの現在のAnimation Rangeをそのまま使用します。ON中は開始 / 終了欄を直接変更しません。
開始 / 終了「アニメーション範囲を使用」がOFFのときに計算範囲を指定します。
ループ同じ範囲を追加で計算し、ループ動作を馴染ませる補助です。完全なシームレスを保証するものではありません。
ポーズ合わせ計算前の子ノード姿勢を補助参照としてサンプルします。元アニメーションの姿勢変化、特にUp / ねじれ方向を維持したい場合に使います。
サブフレームキーを削除サブフレーム計算で作られた整数フレーム以外のキーを計算後に削除します。初期値ONです。

7. 当たり判定

SpringMaxでは、シーン内に作成した球とボックスを衝突物として使用します。カプセル・平面は使用しません。

作成手順

衝突物を置きたい位置のノードを選択します。未選択でも作成できます。
「球作成」または「ボックス作成」を押します。
Move / Rotate / Scale、または球Radius・Boxサイズを調整して身体などへ配置します。
揺らす骨だけを選択し直します。
「衝突判定を有効化」をONにして「適用」します。
衝突物は適用時に選択する必要はありません。 SpringMaxが作成した球 / ボックスをシーン内から自動検索します。
項目初期値説明
当たり余白0.000見た目の衝突物より、この値だけ外側へ膨らませて判定します。めり込み防止に使用します。
復帰の固さ0.150衝突を抜けた後、通常の軌道へ戻る速さです。小さいほどじわっと戻り、1.0に近いほど早く戻ります。
関節連動0.650関節付近で1本だけ急角度にならないよう、下位骨の補正を上位骨へ分散する強さです。

使い分け

球

頭、肩、胸、関節など丸い領域向け。非等方スケールした場合も安全側の球として判定します。

ボックス

胴体、背中、板状パーツなどに向いています。回転したボックスにも対応します。

骨の支点そのものが衝突物内部にある場合、その支点を外へ移動することはできません。子側を逃がす方向で補正します。

8. 風

風は円錐オブジェクトで方向を指定します。円錐の先端方向（ローカルZ+）が風向きです。

設定手順

「風オブジェクト作成 / 値更新」を押します。風用の円錐が無ければ新規作成されます。
円錐を回転して風向きを決めます。
最大風力・最小風力・周波数・先端なびき倍率を設定します。
「風を有効化」をONにして骨を選択し、「適用」します。
項目初期値説明
最大風力100.000風が強いタイミングの強さ。014以降は風方向へ滑らかに寄せる方式で、強風時の急反転を抑えています。
最小風力0.500風が弱いタイミングの強さ。
周波数1.000風の周期。1.0で約30フレームに1周期です。
先端なびき倍率2.50先端ほど強く風を受ける倍率。1.0で均一、値を上げるほど毛先側が大きくなびきます。
骨ごとに少し位相差を付けているため、チェーン全体が同じ角度で傾くだけではなく、根元から先端へ波が伝わるようになびきます。
風を有効化しているのに風オブジェクトが無い場合は計算できません。先に「風オブジェクト作成 / 値更新」を押してください。

9. 重力

重力も円錐オブジェクトで方向を指定します。円錐の先端方向（ローカルZ+）が重力方向です。必ずワールド-Z固定ではないため、演出上の任意方向へ引っ張る用途にも使えます。

「重力オブジェクト作成 / 値更新」を押します。
円錐を回転し、引っ張りたい方向へ先端を向けます。
「重力の強さ」を設定します。
「重力を有効化」をONにして「適用」します。

初期値: 重力の強さ 1.000

風・重力は、それぞれの有効化チェックがOFFなら、シーン内に円錐が残っていても計算へ使用しません。

10. 基準角度

SpringMaxは、何度衝突してもロール角が累積して根元が回り続けないよう、必ず基準姿勢へ戻ろうとします。

基準姿勢の優先順位

  1. 「角度を保存」している骨 → 保存したローカル角度
  2. 保存していない骨 → 「適用」を押した瞬間のローカル角度
ボタン動作
角度を保存現在選択している各ノードの角度を基準として保存します。Maxファイル内のUser Propertyにも保持されます。
保存角度に戻す選択ノードを保存済み角度へ戻します。
保存角度を解除選択ノードの保存基準を解除します。次回適用時は、その時点の角度が基準になります。
キャラクターの「正しい待機姿勢」が決まっている場合は、計算前に骨を選択して「角度を保存」しておく運用がおすすめです。

11. 骨ポーズ

ボタン説明
コピー選択ノードの現在Transformを一時保存します。
貼り付け同じノードへ一時保存したTransformを戻します。コピー情報はSpringMaxを実行しているPythonセッション中の一時情報です。
直線化選択ノードを最初の子ノード方向へ向けます。チェーンの初期姿勢を整える補助機能です。

13. トラブル対処

症状確認すること
一番上の骨が動かない「ルート骨も計算」がOFFなら仕様です。一番上も揺らしたい場合はONにします。
分岐地点で動きが止まる「分岐骨も計算」がONか確認します。018では初期値ONです。
末端の骨が回転しないその骨の向きを決める子 / Endノードまで選択されているか確認します。
衝突を抜けた瞬間に急に戻る「復帰の固さ」を下げます。0.10～0.15付近から確認してください。
関節だけ急に折れる「関節連動」を上げます。球 / ボックスが関節の支点へ食い込みすぎていないかも確認します。
根元が何度も回ってしまう「角度を保存」で正常姿勢を保存してから再計算します。以前の保存角度が不要なら一度「保存角度を解除」します。
何もしていないのに周期的に動く「風を有効化」「重力を有効化」が意図せずONになっていないか確認します。
風力を変えても変化がない風を有効化し、風オブジェクトが存在するか確認します。018は「適用」時にUIの風値を既存風オブジェクトへ同期します。
風の向きが違う風円錐のローカルZ+、つまり円錐先端方向を確認します。
重力方向が違う重力円錐の先端方向が重力方向です。
高速動作で不安定サブフレームを2～4へ増やして再計算します。
結果がおかしくなったCtrl + Z 1回で適用前へ戻します。

14. 注意事項

  • 3ds Max 2025以降を対象としています。
  • ローカルX軸が子方向を向く一般的なBone系リグを前提としています。
  • 特殊なController、Biped / CATなどは通常Boneと挙動が異なる場合があります。
  • 「適用」は指定範囲内の対象回転キーを作り直します。重要なアニメーションは保存してから実行してください。
  • 風 / 重力がONの場合、それぞれシーン内で最初に見つかったSpringMax用オブジェクトを計算に使用します。
  • 球 / ボックス / 風 / 重力は、通常の3ds Maxオブジェクトとして移動・回転・スケールできます。ただしSpringMax識別情報を消すと自動認識されなくなります。
  • 数値欄でEnterを押しても球・ボックス等は作成されません。オブジェクト作成は各作成ボタンを押したときだけ行われます。
推奨: 本番データで初めて試す前に、簡単なBoneチェーンで設定を確認してください。特に当たり判定・風・重力は一度に全部ONにせず、1機能ずつ確認すると原因を切り分けやすくなります。
