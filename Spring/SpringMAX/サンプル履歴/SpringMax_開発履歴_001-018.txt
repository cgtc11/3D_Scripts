SpringMax 開発履歴
作成日: 2026-08-24
対象: SpringMax 018 まで

============================================================
1. 概要
============================================================

SpringMaxは、もともとMaya向けに作られていたSpring系ツールを
3ds Max向けに移植・改良してきたツールです。

当初は3ds Max 2022も視野に入れていましたが、
途中から3ds Max 2025以降 + PySide6専用に方針変更しました。

最終的には、
・Spring
・風
・重力
・球 / BOX当たり判定
・当たり後の復帰
・関節連動
・基準角度保存
・分岐骨対応
・ルート骨対応
などを備える構成になっています。

4. 主な問題と対策
============================================================

1. 骨全体が壊れる
→ ワールド回転の扱いを修正し、位置を維持した回転へ変更。

2. 新版を起動しても旧版UIが出る
→ Pythonモジュールキャッシュ対策として内部名もナンバリング。

3. 当たり判定がゆるい
→ 球 / BOXへ簡略化し、骨軸全体や計算後Bone位置でも再判定。

4. 当たり判定後に急激に戻る
→ 復帰の固さを追加。

5. 関節が1箇所だけ急角度に折れる
→ 関節連動を追加。

6. 衝突を繰り返すと根元が回転し続ける
→ 計算開始時 / 保存角度を基準姿勢として固定し、ロール累積を防止。

7. 何もしていないのに突然ピクッと動く
→ 風 / 重力の自動有効化を廃止。
→ 回転軸安定化とEuler連続化を追加。

8. 当たり判定後に元へ戻らない
→ 復帰中の姿勢を基準として上書きしないよう修正。
→ 必ず計算開始時 / 保存角度へ戻す仕様へ整理。

9. 風で根元だけが揺れる
→ 先端ほど強く風を受ける方式へ変更。
→ 位相差と先端なびき倍率を追加。

10. 強風で先端骨が突然回る
→ 風方向へ滑らかに寄せる方式へ変更。

11. 分岐階層の一部しか計算されない
→ 選択された複数枝を別チェーンとして自動処理。
→ 分岐骨もON/OFFで計算可能に変更。

============================================================
5. 現在の基本方針
============================================================

・3ds Max 2025以降を対象とする。
・PySide6を使用する。
・1ファイルで配布・実行できる構成とする。
・不要な画像や外部UI素材は使わない。
・新しい版は必ずナンバリングして旧版を上書きしない。
・計算開始時の姿勢、または保存角度へ必ず戻る。
・風や衝突によって骨が突然反転 / 累積回転しないことを優先する。
・選択された親子階層、分岐階層を可能な限りまとめて処理する。
・当たり判定は扱いやすさを優先し、球 / BOXを基本とする。

============================================================
6. 今後の移植案
============================================================

SpringMaxの計算ロジックを共通化し、
Maya版 / Blender版へ移植することは可能。

想定:
・SpringMax
・SpringMaya
・SpringBlender

理想的には、
Spring / 風 / 重力 / 当たり判定などの数学部分を共通化し、
各DCCごとに
・骨姿勢取得
・回転適用
・キー作成
・UI
だけを切り替える構成とする。

Maya:
・元ツールがMaya版だったため比較的移植しやすい。

Blender:
・bpy / Pose Bone / matrix_basis / Quaternion等への置換が必要。
・Quaternion中心に作ることでEuler反転問題を避けやすい可能性がある。
