# Tab Manager 使い方説明書

Blenderのサイドバー(Nパネル)に並ぶタブを、フォルダにまとめて整理するアドオンです。
対応バージョン: **0.1** (`tab_manager_v0_1.py`)

※ v1〜v11までは整数のバージョン表記(1.0.0 〜 11.0.0)を使っていましたが、
これ以降は 0.1 からの表記に変更しています。中身(機能)はv11から変更ありません。
※ ファイル名に「0.1」とピリオドを入れると、Pythonのモジュール名としてピリオドが
パッケージ区切りと誤解釈され、Blenderへのインストールに失敗するため、
ファイル名は `tab_manager_v0_1.py`（アンダースコア区切り）にしています。
`bl_info` 内の内部バージョン番号自体は `(0, 1, 0)` のままです。

---

## 1. インストール

1. Blenderの `編集 > プリファレンス > アドオン` を開く
2. 右上の「▼」から「ディスクからインストール」を選び、`tab_manager_v0_1.py` を指定
3. 一覧に出てくる「Tab Manager」にチェックを入れて有効化

すでに古いバージョン(v1〜v11)を入れている場合は、先にそちらを無効化・削除してから
0.1を入れてください（同時に有効化すると、タブの奪い合いが起きる可能性があります）。

※ 今後 0.2、0.3…と続く場合も、ファイル名には `tab_manager_v0_2.py` のように
アンダースコアを使い、ピリオドは入れません（Pythonのモジュール名にピリオドを
含めるとBlenderへのインストールに失敗するため）。

---

## 2. 基本の考え方

| 用語 | 意味 |
|---|---|
| **タブ** | Nパネル右端に並ぶ、あのアイコンの列のこと。Blender内部では `bl_category` という名前で管理されている |
| **フォルダ** | 本アドオンで新しく作る「タブの入れ物」。フォルダ名がそのまま新しいタブの名前になる |
| **未整理** | まだどのフォルダにも入れていない、既存のタブ |
| **基本タブ** | Blender標準搭載のタブ(Item/Tool/View/Animationなど)や、Blenderに同梱されている公式アドオン/拡張機能のタブ(glTF I/Oなど)。デフォルトでは一覧に出てこない |
| **共有タブ警告(⚠)** | 同じタブ名を複数の別々のアドオンが使っている可能性がある場合に表示される注意マーク。除外はしないが、まとめて動かすと意図しない組み合わせになる場合があるので確認してから使うことを推奨 |

**1つのタブに複数のパネル(パーツ)が最初からまとまっている場合**、本アドオンはそれを
「1つのタブ」として扱います。未整理一覧には `タブ名（N件のパネル）` のように表示され、
フォルダへ入れる際は中のパネル全部がまとめて移動します。

---

## 3. 使い方の流れ

### 手順1: スキャン
プリファレンスの「スキャン」ボタンを押す。現在有効なアドオンのタブを検出し、
一覧に表示します。アドオンを追加/削除したときは、必ずもう一度スキャンしてください。

### 手順2: フォルダを作る
「＋ フォルダを追加」で新しいフォルダを作成。名前は後からいつでも変更できます
（この名前がそのままNパネルのタブ名になります）。

### 手順3: タブをフォルダへ入れる
「未整理」に並んでいるタブの「フォルダへ入れる」ボタンを押し、入れたいフォルダを選ぶ。
複数のタブを同じフォルダに入れると、Nパネル上ではそれらが1つのタブにまとまります。

### 手順4: 適用
「適用」ボタンを押すと、実際のNパネルに反映されます。
反映されない場合は、サイドバー(N)を一度閉じて開き直してください。

### 手順5: 並び替え
フォルダの右上にある ▲▼ ボタンで、フォルダの並び順(＝Nパネルのタブの並び順)を変更できます。
「適用」を押すたびに、フォルダの並び順に沿って管理対象タブ同士の相対順序が反映されます。
※ 未管理の他アドオンのタブとの位置関係までは制御できません。

### 手順6: フォルダから出す／フォルダを削除する
- 個別のタブだけをフォルダから出す: フォルダ内の項目にある「×」ボタン
- フォルダごと削除する: フォルダ右上の「×」ボタン（中のタブは消えず「未整理」に戻ります）

どちらの場合も、**もう一度「適用」を押すことで、対象のタブは元のタブ名に戻ります**。
（v6以降で対応。それより前のバージョンでは、フォルダを消しただけでは反映されず
「すべて元に戻す」を押す必要がありました。）

---

## 4. 重要な注意事項

### 中身が空のフォルダは、Nパネルに表示されません
Blenderのタブは「そのタブ名(`bl_category`)を持つパネルが実際に存在する」ことで
初めて画面に現れます。空のフォルダにはパネルが1つも紐付いていないため、
「適用」を押してもNパネル上には何も表示されません。これは仕様であり、不具合ではありません。
タブとして表示させたい場合は、必ず未整理のタブを1つ以上そのフォルダへ入れてください。

### 「基本タブは無視する」をONにしていると出てこないタブがある
Blender標準タブ・同梱アドオンのタブは、デフォルトで一覧から除外されます。
除外の判定は「タブ名」ではなく「そのパネルを定義しているファイルの場所」で行っています
(Blenderのインストール先の中にあるかどうか)。まれに正しく判定できないケースがあった場合は、
次の「デバッグ情報を表示」で原因を確認してください。

### 並び順の制御には限界があります
タブの並び順を完全に自由な位置へ持っていく公式APIはBlenderに存在しません。
本アドオンは、管理しているタブ同士を再登録し直すことで相対的な順序を制御していますが、
未管理の他アドオンのタブとの位置関係までは保証できません。

## 5. デバッグ情報の見方

タブが期待通りに表示されない・消える等の問題が起きた場合、
プリファレンスの「デバッグ情報を表示」にチェックを入れると、
現在検出できている全タブについて次の情報が見られます。

- **タブ名**：Blender上のタブ名(`bl_category`)
- **パネル**：そのタブに含まれるパネルのラベルとID
- **モジュール**：そのパネルを定義しているPythonモジュール名
- **同梱扱い**：「基本タブは無視する」設定でこのタブが除外対象になっているかどうか
- **ファイルの場所**：そのモジュールの実ファイルパス

期待と違う結果になっている場合は、この情報を控えて開発者へフィードバックすると
原因の特定がしやすくなります。

---

## 6. プリセットの保存・読み込み

「プリセットを保存」で、現在のフォルダ構成をJSONファイルとして保存できます。
「プリセットを読み込み」で、保存したJSONファイルからフォルダ構成を復元できます。
読み込み時は自動的にスキャンとタブの再割り当て・適用が行われます。

※ 異なるバージョン間(例: v3のプリセットをv4以降で読み込む等)での互換性は保証していません。
データ構造が変わったバージョンをまたぐ場合は、新しいバージョンで作り直してください。

---

## 7. 起動時の自動適用

Blenderを起動する(または他のアドオンが読み込まれる)たびに、
「起動時の適用待機時間(秒)」で指定した時間だけ待ってから、自動的に「適用」と同じ処理が
実行されます。他のアドオンの読み込みが遅い環境では、この時間を長めに設定してください。

---

## 9. 表示言語(日本語⇔英語)について

v8以降、Blenderの `編集 > プリファレンス > インターフェース > 翻訳 > インターフェースを翻訳`
がONになっていて、かつ言語設定が英語(English)になっている場合、本アドオンのUI表示
（ボタン名・説明文・注意書きなど）は自動的に英語表示に切り替わります。
日本語のままの場合は、そのまま日本語で表示されます。特別な設定は不要です。

※ 一部、件数やファイルパスなど動的に組み立てられる文言についても翻訳対応していますが、
実際にBlender上でどう表示されるかは、こちらの開発環境(Blenderの無い環境)では
最終確認できていません。表示が崩れる・翻訳が反映されない箇所があれば教えてください。

※ アドオン一覧（プリファレンス > アドオン）に出る短い説明文だけは、
翻訳の仕組みが効くかどうかを確認できなかったため、v10より英語表記で固定しています。
日本語環境でもここだけは常に英語で表示されます。

## 10. バージョン履歴

| バージョン | 主な変更点 |
|---|---|
| v1 | 初版。タブの改名・並び替え・プリセット保存/読込 |
| v2 | フォルダ機能を追加（複数タブを1つのフォルダにまとめて統合管理） |
| v3 | 「基本タブは無視する」機能を追加。共有タブ名の検出ロジックを実装 |
| v4 | 同じタブ名の複数パネルを「1つのタブ」としてグループ化するよう変更。同梱アドオン判定をファイルパスベースに変更 |
| v5 | Blender 4.2以降の拡張機能(Extensions, `bl_ext.*`)の名前空間に対応。判定基準をBlenderインストール先ベースに変更。デバッグ情報表示を追加 |
| v6 | フォルダを削除した後、「適用」を押すだけで元のタブ名に戻るよう修正 |
| v7 | 「中身が空のフォルダはNパネルに表示されない」旨の注記をUIに追加 |
| v8 | Blenderの言語設定(日本語/英語)に応じてUI表示を自動切り替えできるよう、翻訳(i18n)対応を追加 |
| v9 | 「＋ フォルダを追加」等、ボタンの文字を上書きしている箇所で翻訳が反映されないバグを修正(翻訳の文脈(context)指定漏れ) |
| v10 | アドオン一覧に表示される説明文(bl_infoのdescription)は翻訳の仕組みが効かないため、英語固定表記に変更 |
| v11 | メンテナー表記を「デザ」から「DiGiMonkey」に変更 |
| 0.1 | バージョン表記をv11(11.0.0)から0.1に変更(以降はこの表記を継続)。機能変更なし。※ファイル名に含めたピリオドが原因でインストール不可になっていたため、`tab_manager_v0_1.py`に修正済み |

---

## 9. 既知の制限事項（正直な申告）

- タブの並び順の完全な自由な制御はBlenderの仕様上できません
- 拡張機能(Extensions)のモジュール名の扱いは、Blenderのバージョンや
  リポジトリ構成によって変わる可能性があり、100%全ての環境で正しく動作する保証はありません
  （「デバッグ情報を表示」で都度確認してください）
- 異なるバージョンのプリセットJSON間の互換性は保証していません
- 英語UIへの翻訳は主要な文言をカバーしていますが、全ての表示パターンを
  実際のBlender上で目視確認できているわけではありません
