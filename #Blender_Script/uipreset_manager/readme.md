# UI Layout Preset Manager 説明書

Blenderで「UIレイアウト」と「アドオン有効化状態」をプリセットとして記憶・切替できるアドオンです。

対象ファイル: `uipreset_manager_v14.py`


## インストール

1. Blenderで `編集 > プリファレンス > アドオン` を開く
2. 右上の「インストール」から `uipreset_manager_v14.py` を選択
3. 一覧に出てくる「UI Layout Preset Manager」にチェックを入れて有効化

有効化すると、3Dビューポートのサイドバー(キーボードの `N` で開閉)に **「Upri」** タブが追加されます。ここに2つのパネルが表示されます。

- UIプリセット(レイアウト)
- アドオン有効化プリセット


## 1. UIプリセット(レイアウト)

### できること

現在開いているファイルの状態を「テンプレートファイル」として丸ごと保存し、いつでもそこに切り替えられます。

### 使い方

| 操作 | 内容 |
|---|---|
| **記憶** | 現在の状態に名前を付けて保存するダイアログが開きます。名前は自動的に「設定1」「設定2」…のように、まだ使われていないものが提案されます |
| リスト選択 | 一覧から戻したいプリセットをクリックして選択 |
| **削除** | 選択中のプリセットを削除(確認ダイアログあり) |
| ✏(名前変更) | 選択中のプリセットの名前を変更するダイアログが開きます |
| **この状態に戻す** | 選択中のプリセットに **即座に** 切り替わります(確認ダイアログなし) |
| 更新 | 保存フォルダの中身とリストを手動で再同期します(通常は不要) |

### ⚠️ 重要な注意点

**「この状態に戻す」を押すと、現在編集中のシーンのデータ(オブジェクト・メッシュなど)は破棄され、保存しておいたテンプレートファイルの中身に完全に置き換わります。**

これは Blender の `read_homefile()`(スタートアップファイルの読み込み)という仕組みをそのまま使っているためで、「UIの見た目だけ変えて、今の作業内容はそのまま残す」ことはできません。

- ✅ 向いている使い方: 新規作業を始める際に、決まったレイアウト・初期設定から始めたい場合
- ❌ 向いていない使い方: 作業中のプロジェクトの見た目だけを一時的に変えたい場合(この用途には対応できません)

**未保存の変更がある状態で「この状態に戻す」を押すと、その変更は失われます。** 大事な作業中は先に `Ctrl+S` などで保存してから使ってください。

### 保存先

```
%APPDATA%\Blender Foundation\Blender\<バージョン>\config\ui_presets\
```

この中に、プリセットごとの `.blend` ファイルと、並び順を管理する `ui_presets_order.json` が保存されます。


## 2. アドオン有効化プリセット

### できること

「今どのアドオンが有効になっているか」の組み合わせをプリセットとして保存し、後から呼び出せます。UIプリセットと違い、**シーンのデータには影響しません**。

### 使い方

| 操作 | 内容 |
|---|---|
| **記憶** | 現在有効なアドオンの一覧を「Addon Preset 1」のような名前で保存します |
| リスト選択 | 一覧から呼び出したいプリセットをクリックして選択 |
| **削除** | 選択中のプリセットを削除 |
| ✏(名前変更) | 選択中のプリセットの名前を変更するダイアログが開きます |
| **この状態に戻す** | 選択中のプリセットの内容と **完全に一致** させます。プリセットに含まれていないアドオンは無効化されます |

### ⚠️ 重要な注意点

- 「この状態に戻す」を押すと、プリセットに含まれていないアドオンは **無効化されます**。このアドオン自身は誤って無効化されないよう保護されています。
- 名前・メールアドレス・シリアルナンバーなどの入力欄を持つアドオン(ライセンス認証が必要なものなど)は、無効化→有効化のタイミングでその入力内容がクリアされ、再入力が必要になる場合があります。これはそのアドオン自身の実装によるもので、このアドオン側では制御できません。
- 同様に、「有効だけどパネル表示だけ消す」といった、有効/無効の中間状態はBlenderの仕組み上存在しないため実現できません。

### 保存先

```
%APPDATA%\Blender Foundation\Blender\<バージョン>\config\ui_presets\addon_presets.json
```

UIプリセットとは別のファイルで、どの `.blend` を開いていても消えずに保持されます。
